# 🐍 100 Days of Code - Python

This repository contains my solutions, exercises, and projects from the **100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

My goal is to code every day, improve my Python skills, and build a portfolio of projects along the way.

## 🎯 Goals

- Learn Python from beginner to advanced
- Practice coding every day
- Build 100 projects
- Learn web development, automation, APIs, databases, and data science
- Build a portfolio for future opportunities
